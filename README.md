# CYBERSHIELD-

CYBERSHIELD 🛡️

Cyber Security Awareness and Simulation System

A Python-based cybersecurity awareness application developed for Class XII Informatics Practices.

Features

- Password Strength Checker
- Phishing Message Analyser
- Caesar Cipher Encryption and Decryption
- Firewall Rule Simulator
- Cybersecurity Awareness Notes
- Cyber Safety Quiz
- SQLite Activity Dashboard

Technologies Used

- Python
- Tkinter
- SQLite
- Regular Expressions

Requirements

- Python 3.x
- Tkinter (usually included with Python)

How to Run

python cybershield.py

The SQLite database is created automatically when the application runs.

Disclaimer

This project is designed strictly for educational purposes. All simulations work offline using sample data. It does not scan devices, access networks, or modify system firewall settings.

Passwords entered into the password checker are not stored.
